## ▶️ How to run

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
cd NHapMonLapTrinh/NHapMonLapTrinh
dotnet run
```

Or open the `.slnx` file in Visual Studio and press **F5**.
